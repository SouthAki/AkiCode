# Review 输出约定

只报告有源码证据、由当前变更引入且可行动的问题。优先精确和低噪声，不按文件数量凑结论。

## 严重程度

- **P1**：高概率导致数据损失、严重安全/隐私问题、主要功能不可用，且无需特殊条件即可触发。
- **P2**：常见使用路径中的实质性错误、回归或安全缺陷。
- **P3**：影响较窄但值得修复的正确性/兼容问题。风格偏好不算 finding。

## 格式

```text
[P2] 订单重试会重复扣款
`src/payments/retry.ts:84`
重试分支在请求超时后未确认原交易状态，第二次提交会创建新的扣款。先按幂等键查询或重放原请求。
```

行号应来自当前文件，并尽量位于 Diff 的新增/修改行。不要给未经验证的建议标严重等级。若没有可行动问题，报告已审查的文件数量和范围，并明确“未发现可行动问题”。
